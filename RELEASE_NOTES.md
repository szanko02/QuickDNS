### QuickDNS v2.3.1 - DNS-AI (DoH) SmartDNS Preset, RFC 8484 DoH Engine Fallback & Add Profile UI Overhaul

Feature, networking engine, and High-DPI dialog consistency update for standard MIT-licensed QuickDNS. Version `2.3.1` introduces the built-in `DNS-AI (DoH)` encrypted SmartDNS preset, full RFC 8484 DNS-over-HTTPS and RFC 7858 DNS-over-TLS fallback across the benchmark, AI availability checker, SmartDNS verifier, and real-time sparkline monitor, a redesigned `PerMonitorV2` Add Profile dialog, and an interactive owner-drawn SmartDNS card fix for GitHub Issue #2:

- **DNS-AI (DoH) SmartDNS Preset & Config Migration (`ConfigManager`, `SmartDnsDialog`, `default_profiles.json`)**: Added the built-in `dns_ai` (`DNS-AI (DoH)`) SmartDNS profile (`194.87.196.13` / `45.151.102.219`, IPv6 `2a00:b700:5::3:62` / `2a12:5940:d4ef::219`, DoH endpoint `https://dns.dns-ai.ru/dns-query`) for AI services (`ChatGPT`, `OpenAI`, `Claude`, `Gemini`, `Google AI Studio`, `Microsoft Copilot`, `Grok`, `Cursor`) with built-in ad/tracker filtering and automatic configuration migration from earlier `profiles.json` schemas.
- **RFC 8484 HTTP/2 DoH & RFC 7858 DoT Engine Fallback (`AiChecker`, `DnsBenchmark`, `SmartDnsVerifier`, `MainWindow`)**: Implemented `AiChecker::resolve_domain_via_doh` (WinHTTP HTTP/2 `application/dns-message` `POST` with `?dns=` base64url `GET` fallback) and direct Schannel bootstrap resolution (`resolve_via_bootstrap_ip` over DoT `:853` and HTTPS `:443` with SNI verification) when UDP/TCP port 53 is intentionally disabled by DoH-only providers, added `DnsBenchmark::ping_doh_server_domain` with pooled HTTP/2 connection retry in batch benchmarks and real-time sparkline monitoring, and preserved DoH-only primary/secondary IPs and `ip_pool` during `SmartDnsVerifier::verify_profile` and `apply_best_ips`.
- **Add Profile Dialog Overhaul & SmartDNS Toggle Fix (`AddProfileDialog`)**: Fixed GitHub Issue #2 where `BS_OWNERDRAW` ignored standard `BM_GETCHECK` / `BM_SETCHECK` messages so the SmartDNS option could not be toggled or saved; redesigned `AddProfileDialog` to match the application's modern GDI+ card layout with a grouped input card, side-by-side IPv4 fields, required/optional header hints, edit cue banners (`EM_SETCUEBANNER`), focus/validation glow rings, a full-width interactive `SmartDnsCardSubclassProc` toggle card (`BM_GETCHECK` / `BM_SETCHECK` / `BM_CLICK`, mouse hit-testing, and keyboard `VK_SPACE`), and dynamic `PerMonitorV2` DPI scaling.
- **Windows 10 DoH Guard & CTest Suites (`MainWindow`, `tests/*`)**: Added a `RtlGetVersion` build check (`dwBuildNumber < 22000`) in `MainWindow::apply_selected_dns` warning Windows 10 users before applying DoH-only adapter profiles (with browser Secure DNS instructions), updated `SmartDnsDialog` status badges to display green `DoH OK` latency on DoH-only resolvers, and expanded `test_config` and `test_smartdns_verifier` CTest suites for `dns_ai` preset parity, migration, candidate discovery, and DoH-only IP preservation.

### Краткое описание (Русский)

Обновление сетевого движка, встроенных пресетов и графического интерфейса стандартной версии QuickDNS (лицензия MIT). В релизе `v2.3.1` добавлен шифрованный профиль `DNS-AI (DoH)`, реализован автоматический переход на RFC 8484 DoH и RFC 7858 DoT для провайдеров с закрытым портом 53 во всех модулях диагностики, полностью обновлен дизайн окна добавления профиля и исправлен переключатель SmartDNS (GitHub Issue #2):

- **Встроенный пресет DNS-AI (DoH) и автомиграция конфигурации (`ConfigManager`, `SmartDnsDialog`, `default_profiles.json`)**: Добавлен встроенный профиль `dns_ai` (`DNS-AI (DoH)` — `194.87.196.13` / `45.151.102.219`, IPv6 `2a00:b700:5::3:62` / `2a12:5940:d4ef::219`, шаблон `https://dns.dns-ai.ru/dns-query`) для доступа к ИИ-сервисам (`ChatGPT`, `OpenAI`, `Claude`, `Gemini`, `Google AI Studio`, `Microsoft Copilot`, `Grok`, `Cursor`) с блокировкой рекламы и телеметрии, карточкой в каталоге SmartDNS и автоматической миграцией существующих файлов `profiles.json`.
- **Поддержка DoH-only серверов по RFC 8484 HTTP/2 и RFC 7858 DoT (`AiChecker`, `DnsBenchmark`, `SmartDnsVerifier`, `MainWindow`)**: Реализован резолв `AiChecker::resolve_domain_via_doh` через WinHTTP HTTP/2 (`POST` и `GET ?dns=`) и прямое резервное подключение через Schannel (`resolve_via_bootstrap_ip` по DoT `:853` и HTTPS `:443` с проверкой SNI) для серверов с намеренно закрытым портом UDP/TCP 53, добавлен замер задержки `DnsBenchmark::ping_doh_server_domain` в многопоточном бенчмарке и фоновом графике пинга на главном окне, а также сохранение эталонных IP-адресов DoH-only профилей в `SmartDnsVerifier::verify_profile` и `apply_best_ips`.
- **Переработка окна добавления профиля и исправление флага SmartDNS (`AddProfileDialog`)**: Исправлена ошибка GitHub Issue #2, из-за которой кнопка со стилем `BS_OWNERDRAW` игнорировала системные сообщения `BM_GETCHECK` / `BM_SETCHECK` и не сохраняла флаг SmartDNS; окно `AddProfileDialog` приведено к единому стилю остальных разделов приложения (скругленная GDI+ карточка полей, двухколоночный ввод IPv4, индикаторы обязательных полей, подсказки `EM_SETCUEBANNER`, подсветка фокуса и ошибок валидации, интерактивная карточка-переключатель `SmartDnsCardSubclassProc` с поддержкой мыши, пробела и `BM_GETCHECK`/`BM_SETCHECK`, а также масштабирование `PerMonitorV2` High-DPI).
- **Предупреждение о DoH в Windows 10 и покрытие тестами CTest (`MainWindow`, `tests/*`)**: Добавлена проверка сборки ОС через `RtlGetVersion` (`dwBuildNumber < 22000`) при применении DoH-only профиля в Windows 10 с рекомендацией настройки Безопасного DNS в браузере, обновлено отображение зеленого статуса `DoH OK` в каталоге SmartDNS и расширены модульные тесты `test_config` и `test_smartdns_verifier`.
