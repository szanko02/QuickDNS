### QuickDNS v2.2.5

This preview updates the two-network routing window and keeps each edition on its own update channel.

- **Two-network routing** — Choose the primary and secondary networks, save them, and start or stop routing from one window. External HTTP and HTTPS sites use the secondary network. Local traffic uses the primary network.
- **In-app help** — Hover over **?** for a short explanation of which traffic uses each network. The window no longer shows the subnet tab, application rules, or the yellow notice.
- **Updates by edition** — The embedded edition finds newer releases with the matching embedded executable and checksum, including previews. The compact edition follows the stable channel. Before replacing the executable, QuickDNS verifies its checksum and edition.
- **Installation** — Users of an older embedded edition can install this preview by downloading QuickDNS-Embedded.exe directly.

#### Описание изменений

- **Маршрутизация** — Выбор и сохранение двух сетей, запуск и остановка в одном окне. Внешние HTTP/HTTPS-сайты используют вторичную сеть, локальный трафик — основную.
- **Интерфейс** — Краткая справка по значку **?**. Блок правил приложений, вкладка «Подсети» и жёлтое уведомление убраны.
- **Обновления** — Встроенная версия подбирает релизы с таким же движком, включая предварительные. Компактная версия проверяет стабильный канал. Перед заменой файла программа проверяет SHA-256 и редакцию.
- **Установка** — Для перехода со старой встроенной версии скачайте QuickDNS-Embedded.exe вручную.
