### QuickDNS v2.3.0 - Security Hardening, Windows 11 DoH v3, TLS 1.3 AI Probing, High-DPI & Stability Overhaul

Major security, networking, UI/High-DPI, and concurrency hardening release for standard MIT-licensed QuickDNS. Version `2.3.0` delivers hop-by-hop HTTPS update validation, native Windows 11 `DNS_INTERFACE_SETTINGS3` DNS-over-HTTPS support, full TLS 1.3 Schannel post-handshake renegotiation in AI availability probing, `PerMonitorV2` High-DPI scaling across all dialogs, and clean auto-update convergence onto the main branch:

- **Auto-Updater & Supply-Chain Security (`AppUpdater`, `main`)**: Enforced hop-by-hop HTTPS redirect verification (`WINHTTP_OPTION_REDIRECT_POLICY_NEVER`, max 5 hops, strict port 443 and host/path allowlisting), constant-time BCrypt SHA-256 comparison, 25 MB executable size cap, exact `QuickDNS.exe` / `QuickDNS.exe.sha256` asset matching (eliminating wildcard `.exe` fallback), draft/pre-release exclusion with SemVer 2.0.0 pre-release precedence, `SetDefaultDllDirectories(LOAD_LIBRARY_SEARCH_SYSTEM32)` startup protection, and PID-synchronized `--updated --pid` restart handoff without worker-thread `ExitProcess`.
- **Windows 10/11 DNS-over-HTTPS v3 & Dual-Stack Engine (`DnsManager`)**: Added `DNS_INTERFACE_SETTINGS3` (`DNS_SETTING_DOH | DNS_SETTING_DOH_PROFILE`) configuration with automatic `VERSION1` fallback on Windows 10, synchronized `DohInterfaceSettings` and `DohProfileSettings` registry state (`DohFlags = 0x6`), exact `EnableAutoDoh` backup and restore lifecycle, Windows 11 build-gated `netsh dns encryption`, dual-stack IPv4/IPv6 DHCP cleanup (`NameServer` and `ProfileNameServer`), canonical `InetPtonW`/`InetNtopW` validation, and `CreateProcessW` `lpApplicationName` hardening.
- **Schannel TLS 1.3 AI Probing & RFC 1035/8484 Verification (`AiChecker`, `SmartDnsVerifier`)**: Implemented TLS 1.3 post-handshake `SEC_I_RENEGOTIATE` (`NewSessionTicket`) handling in Schannel SSPI loops, HTTP `1xx` Early Hints skipping, strict DNS wireformat QNAME/CNAME-chain owner verification and public-unicast IPv4 filtering (rejecting bogon, sinkhole, and RFC1918 addresses), `BCryptGenRandom` TXIDs with EDNS0 (1232B) and TCP port 53 `TC=1` fallback, RFC 8484 DoH DNS wireformat response validation, and bounded 4-thread candidate verification with cooperative cancellation.
- **PerMonitorV2 High-DPI, Multi-Monitor & Modal Lifecycle Overhaul (`MainWindow`, `dialog_*`)**: Fixed GitHub Issue #2 (owner-drawn SmartDNS checkbox state toggle and persistence in Add Profile dialog), implemented `PerMonitorV2` dynamic DPI scaling (`WM_DPICHANGED`, pixel-matched GDI+ typography, and measured SmartDNS catalog card heights), added Windows 10 `Segoe UI` fallback when `Segoe UI Variable Display` is unavailable, clamped window placement to `MonitorFromWindow` work areas, added Precision Touchpad smooth pixel-remainder scrolling, and hardened `WM_DESTROY` / `WM_NCDESTROY` / `WM_QUIT` modal message loops with worker-only `PostMessageW` delivery.
- **Atomic Configuration Persistence & Benchmark Engine (`ConfigManager`, `DnsBenchmark`)**: Added strict lock-ordered `m_save_mutex` atomic `.tmp` + `ReplaceFileW` persistence, non-destructive share-lock retries versus timestamped `.broken` backups for corrupt JSON, automatic `primary_ipv4` / `secondary_ipv4` synchronization into `ip_pool`, full parity with `res/default_profiles.json`, and dual-stack IPv6 fallback with pause-accurate `steady_clock` timing in `DnsBenchmark`.
- **CI/CD Branch Ancestry Gating & CTest Suites (`CMakeLists.txt`, `build.yml`, `tests/*`)**: Separated `quickdns_core` and GUI Win32 link libraries, expanded deterministic offline (`-LE network`, 6 suites) and live network (`-L network`, 4 suites) CTest coverage with non-elided `TEST_CHECK` assertions, and enforced `origin/main` ancestry verification in GitHub Actions so non-main or pre-release tags automatically publish as `prerelease: true` and `make_latest: false`.

### Краткое описание (Русский)

Крупное обновление безопасности, сетевого ядра, масштабирования High-DPI и общей стабильности стандартной версии QuickDNS (лицензия MIT). Релиз `v2.3.0` также обеспечивает корректный автоматический переход через встроенное обновление со всех предыдущих сборок (`v2.0.x..v2.1.0` и промежуточных тегов) на актуальную ветку `main`:

- **Безопасность автообновления и защита процесса (`AppUpdater`, `main`)**: Реализована пошаговая проверка всех HTTPS-редиректов (`WINHTTP_OPTION_REDIRECT_POLICY_NEVER`, до 5 переходов, строгий белый список доменов и порта 443), сравнение SHA-256 через BCrypt за константное время, лимит размера `QuickDNS.exe` (25 МБ), строгая привязка к ассетам `QuickDNS.exe` и `QuickDNS.exe.sha256`, учет SemVer pre-release приоритетов, защита загрузки системных DLL (`LOAD_LIBRARY_SEARCH_SYSTEM32`) и синхронизированный перезапуск `--updated --pid` без аварийного `ExitProcess` из рабочего потока.
- **Поддержка DNS-over-HTTPS v3 в Windows 10/11 и Dual-Stack (`DnsManager`)**: Внедрена настройка через `DNS_INTERFACE_SETTINGS3` (`DNS_SETTING_DOH | DNS_SETTING_DOH_PROFILE`) с автоматическим откатом на `VERSION1` в Windows 10, синхронизация веток реестра `DohInterfaceSettings` и `DohProfileSettings` (`DohFlags = 0x6`), точное сохранение и восстановление `EnableAutoDoh`, проверка сборки ОС для `netsh dns encryption`, корректный сброс IPv4/IPv6 (`NameServer` и `ProfileNameServer`) в DHCP и безопасный запуск системных утилит с явным `lpApplicationName`.
- **Проверка ИИ по TLS 1.3 и валидация RFC 1035/8484 (`AiChecker`, `SmartDnsVerifier`)**: Добавлена поддержка пост-хендшейк пакетов TLS 1.3 `SEC_I_RENEGOTIATE` (`NewSessionTicket`) в цикле Schannel SSPI, пропуск промежуточных ответов HTTP `1xx`, строгая проверка цепочек QNAME/CNAME и фильтрация публичных IPv4-адресов (отсев bogon/sinkhole/RFC1918), криптостойкие `BCryptGenRandom` TXID с поддержкой EDNS0 и резервным переключением на TCP порт 53 при `TC=1`, проверка бинарного DNS-ответа для RFC 8484 DoH и пул потоков с мгновенной отменой задач.
- **Масштабирование High-DPI (`PerMonitorV2`), мультимониторность и диалоги (`MainWindow`, `dialog_*`)**: Исправлен переключатель SmartDNS в окне добавления профиля (GitHub Issue #2), реализовано динамическое масштабирование `PerMonitorV2` (`WM_DPICHANGED`, расчет высоты карточек каталога SmartDNS через `MeasureString`), добавлен автоматический откат шрифта на `Segoe UI` в Windows 10, привязка окон к рабочей области активного монитора, плавная прокрутка для тачпадов Precision Touchpad и потокобезопасное завершение фоновых задач без утечек памяти и взаимных блокировок.
- **Надежное хранение конфигурации и бенчмарк (`ConfigManager`, `DnsBenchmark`)**: Введена атомарная запись `profiles.json` через `.tmp` и `ReplaceFileW` с упорядоченной блокировкой `m_save_mutex`, защита от потери пользовательских профилей при кратковременной блокировке файла и создание резервных копий `.broken` при повреждении JSON, автосинхронизация рабочих адресов с пулом `ip_pool` и поддержка IPv6 в бенчмарке скорости.
- **Сборка, тесты CTest и защита релизов в CI/CD (`CMakeLists.txt`, `build.yml`, `tests/*`)**: Разделены системные библиотеки ядра и GUI, расширено покрытие детерминированных офлайн-тестов (`-LE network`, 6 наборов) и сетевых интеграционных тестов (`-L network`, 4 набора), а в GitHub Actions добавлена проверка принадлежности коммита ветке `origin/main` для защиты `/releases/latest`.
