==================================================
QuickDNS — Быстрая смена DNS в 1 клик для Windows
Версия: v2.3.1
==================================================

КАК ЗАПУСТИТЬ:
1. Запустите файл QuickDNS.exe.
2. При запросе Windows подтвердите запуск от имени Администратора (необходимо для изменения сетевых параметров системы).
3. Выберите нужный DNS-сервер (Comss.one, GeoHide RU/EU/US, Без межаў, Без межаў РФ, Zapret, Malw.link, Astracat, Mafioznik, Shecan, Control D, Akile, DNS-AI (DoH), Cloudflare, Google, Quad9, AdGuard или ваш собственный).
4. Нажмите «Применить DNS в 1 клик» — готово!

ОСОБЕННОСТИ:
- Приложение не требует установки (Portable).
- Проверка доступности нейросетей (ChatGPT, Claude, Gemini, Copilot) через отдельное окно «Проверка ИИ» с прямым TLS/DNS-тестированием каждого профиля без изменения системного DNS.
- Встроенный каталог SmartDNS со списком разблокируемых сервисов, категориями, поиском и автообновлением рабочих IP/DoH.
- Выбор альтернативных IP-адресов из пула нод провайдера (IP Pool Picker) в 1 клик.
- Метки [SmartDNS] для серверов с обходом региональных ограничений нейросетей и онлайн-сервисов.
- Автоматическое определение и синхронизация текущих IPv4/IPv6 DNS-серверов системы при запуске.
- Копируемые IP-адреса и редактируемый шаблон DoH (DNS-over-HTTPS) для Ethernet и Wi-Fi.
- Прямой переход на официальные сайты провайдеров и в системные параметры сети Windows в 1 клик.
- Многопоточный тест скорости (бенчмарк) всех DNS-серверов и sparkline-график стабильности пинга в реальном времени.
- Поддержка темной и светлой темы Fluent Design и масштабирования High-DPI.
- Сворачивание в системный трей возле часов с быстрым переключением DNS по правому клику.
- Настройки и добавленные профили сохраняются в %APPDATA%\QuickDNS\profiles.json.
- Встроенное автообновление программы с проверкой целостности по SHA-256 через Windows BCrypt API.
- Внимание: при выборе SmartDNS DNS-трафик обрабатывается оператором выбранного профиля.
