## Назначение

В стандартном интерфейсе Windows для смены DNS необходимо открывать цепочку системных меню: «Параметры» → «Сеть и Интернет» → «Свойства адаптера» → «IP версии 4» → вручную вводить адреса → подтверждать изменения → выполнять очистку кэша через командную строку.

QuickDNS автоматизирует этот процесс:
1. Выберите сетевой адаптер и нужный профиль DNS (Comss, GeoHide, Zapret, Cloudflare и др.).
2. Нажмите **«Применить DNS в 1 клик»** — настройки применятся мгновенно, а кэш DNS будет очищен.

## Возможности

- **Экспериментальная маршрутизация:** выбор адаптера для приложения через sing-box и настройка маршрутов Windows по IPv4- и IPv6-подсетям. Ограничения и настройка описаны в разделе [«Маршрутизация»](#маршрутизация).
- **Проверка доступности ИИ-сервисов (AI Availability Checker):** отдельное окно со статусом разблокировки ведущих нейросетей (ChatGPT, Claude, Gemini, Copilot) для каждого DNS-профиля с независимым UDP DNS-резолвом (RFC 1035) и прямой TLS-проверкой сокетов через Schannel без изменения системного DNS.
- **Каталог SmartDNS с автообновлением IP и DoH:** встроенный сканер и верификатор рабочих адресов SmartDNS (Comss, GeoHide, Zapret, Без межаў и др.) с проверкой через UDP-сокеты и DoH HTTP/2.
- **Адаптивный современный интерфейс:** полностью отзывчивая верстка всех окон приложения с плавной поддержкой ресайза, темной и светлой темой Fluent Design (Segoe UI Variable), микроанимациями кнопок и чекбоксов.
- **Интерактивный DNS Benchmark:** замер задержки серверов с фильтрацией SmartDNS, выбором доменов нейросетей (ChatGPT, Claude, Notion, Spotify), непрерывным тестированием и автосохранением истории.
- **DNS over HTTPS (DoH):** поддержка DoH шаблонов и валидация соединений.
- **Мгновенное переключение и работа в трее:** смена DNS за доли секунды, автоочистка DNS-кэша (`DnsFlushResolverCache`), контекстное меню в области уведомлений.

* **Смена DNS в один клик:** Мгновенное применение настроек к активному сетевому адаптеру (Ethernet / Wi-Fi) без перезагрузки системы.
* **Проверка доступности ИИ-сервисов (ChatGPT, Claude, Gemini, Copilot):** Комплексный аудит всех DNS-профилей на доступность нейросетей с обнаружением геоблокировок (Cloudflare/OpenAI 403, unsupported country, Cloudflare CDN-CGI trace) и возможностью применить лучший профиль прямо из окна проверки.
* **Метки [SmartDNS]:** Визуальная индикация профилей, автоматически проксирующих трафик для разблокировки зарубежных нейросетей (ChatGPT, Claude, Gemini, Copilot), музыки и стримингов (Spotify, YouTube, Deezer, Netflix), сервисов и рабочих платформ (Canva, Notion, Autodesk, JetBrains).
* **Встроенный интерактивный Каталог SmartDNS:** Отдельное окно с подробными карточками провайдеров, категориями сервисов, поисковым фильтром в реальном времени и кнопками прямого перехода на официальные сайты.
* **Копируемые IP и редактируемый DoH:** Текстовые поля IP-адресов и шаблона DNS over HTTPS доступны для выделения и копирования, а также для ручного редактирования пользовательского шаблона DoH.
* **Переход в параметры сети Windows:** Отдельная кнопка прямого вызова системных настроек сети и DHCP Windows в один клик.
* **Мониторинг задержки и график стабильности:** Встроенный sparkline-график в реальном времени с интервалом обновления 3 секунды и историей пинга за последние 60 секунд.
* **Тестирование скорости всех серверов:** Многопоточный замер времени отклика на пуле популярных доменов с градацией качества и графиками sparkline.
* **Предустановленные профили:** Популярные DNS-серверы для ускорения, защиты и обхода региональных ограничений (Comss.one, GeoHide, Без межаў, Zapret, Malw.link, Cloudflare, Google, Quad9, AdGuard).
* **Добавление собственных профилей:** Диалоговое окно для сохранения пользовательских конфигураций с валидацией IP-адресов и поддержкой DoH-ссылок.
* **Управление профилями:** Удаление пользовательских профилей в один клик.
* **Работа в системном трее:** Сворачивание в область уведомлений, контекстное меню быстрого переключения DNS по правому клику без открытия главного окна.
* **Автоматическая очистка кэша DNS:** Вызов системной функции `DnsFlushResolverCache` после каждой смены конфигурации.
* **Нейтральный интерфейс со сглаживанием:** Сбалансированная цветовая гамма, рендеринг GDI+ с субпиксельным сглаживанием (Anti-Aliasing), выверенные отступы между элементами управления.
* **Переключение темной и светлой темы:** Иконка-переключатель в верхнем углу интерфейса с мгновенной сменой палитры, адаптацией заголовка Windows и сохранением выбора в настройках.
* **Анимация кнопок и курсор-указатель:** Плавное наведение с откликом, тактильная анимация нажатия и курсор в виде указательного пальца при наведении на кнопки.
* **Портативность:** приложение на C++20 и Win32 API со статически подключённой средой C++. Для маршрутизации приложений необходим отдельный sing-box.

## Инструкция по использованию

1. Скачайте [QuickDNS.exe](https://github.com/szanko02/QuickDNS/releases/latest/download/QuickDNS.exe) или откройте [страницу последнего релиза](https://github.com/szanko02/QuickDNS/releases/latest) и скачайте Portable ZIP.
2. Запустите **`QuickDNS.exe`** (при первом запуске подтвердите стандартный запрос UAC для доступа к сетевым параметрам).
3. Программа автоматически выберет ваш активный адаптер (Wi-Fi или Ethernet).
4. Выберите нужный DNS-профиль из выпадающего списка.
5. Нажмите кнопку **«Применить DNS в 1 клик»** — настройки применятся мгновенно.
6. Для быстрого переключения сверните программу в трей: кликните правой кнопкой мыши по значку возле часов и выберите нужный сервер.

## Маршрутизация

В окне **Маршрутизация** есть две вкладки. **Приложения** выбирает сеть по приложению. **Подсети** добавляет системные маршруты по IP-адресу назначения.

### Приложения через sing-box

В сборке со встроенным движком QuickDNS автоматически запускает его при нажатии **Запустить**. Шаг скачивания sing-box и указание пути нужны только для v2.2.0 и сборок без встроенного движка.

Пример настройки для настольного ChatGPT через USB-модем и остальных приложений через Wi-Fi. Подключите обе сети до запуска сеанса. Если в QuickDNS активны маршруты по подсетям, удалите их на вкладке **Подсети** перед запуском sing-box.

1. Скачайте архив Windows x64 из [проверенного релиза sing-box 1.14.4](https://github.com/SagerNet/sing-box/releases/tag/v1.14.4) и распакуйте его в отдельную папку.
2. В QuickDNS откройте **Маршрутизация → Приложения**. В поле **Основная сеть для остальных приложений** выберите Wi-Fi.
3. Выберите **Семейство MSIX** и пакет ChatGPT `OpenAI.Codex_2p2nqsd0c76g0`. Для обычного приложения можно выбрать его EXE.
4. В поле **Сеть приложения** выберите USB-модем. Windows может показывать его под именем **Ethernet**. Нажмите **Добавить**, выделите появившееся правило в списке и нажмите **Сохранить**, чтобы записать список на диск.
5. В поле **Путь к sing-box.exe** через **Обзор…** выберите распакованный файл или вставьте полный путь к нему без кавычек. Нажмите **Запустить** и дождитесь статуса **sing-box и TUN запущены**.
6. Откройте приложение обычным способом. Если оно уже запущено, перезапустите его, чтобы проверить новые соединения. Для завершения сеанса нажмите **Остановить** или выйдите из QuickDNS.

Если QuickDNS просит выбрать правило, убедитесь, что строка появилась после **Добавить** и выделена. **Сохранить** записывает существующий список правил. Если окно выбора файла отклоняет расположение, вставьте полный путь непосредственно в поле.

TUN — виртуальный сетевой адаптер, через который sing-box получает соединения для маршрутизации. QuickDNS поддерживает один активный сеанс с одним выбранным правилом. Режим экспериментальный и разделяет распознанные TCP- и UDP-соединения, попавшие в TUN. DNS-адреса адаптеров отображаются справочно. Системный DNS и трафик вне TUN могут использовать обычные маршруты Windows. Строгая изоляция, включая отказ от переключения на другую сеть при сбое, пока недоступна.

### Маршруты по подсетям

1. Откройте **Маршрутизация → Подсети** в главном окне QuickDNS.
2. Введите IP-подсеть в формате CIDR, например `10.20.30.0/24` или `fd12:3456::/64`, и выберите подключённый адаптер.
3. Укажите IP-адрес шлюза на выбранном адаптере. Оставьте поле пустым, если узлы этой подсети доступны напрямую через адаптер.
4. Нажмите **Применить**. Маршрут появится в списке и в таблице Windows. Windows выбирает более длинный префикс, а при одинаковой длине учитывает метрики маршрута и интерфейса.
5. Проверьте выбор интерфейса в PowerShell командой `Find-NetRoute -RemoteIPAddress 10.20.30.5`, подставив адрес нужного узла. Доступность самого узла проверяется отдельно.
6. Для отмены выделите маршрут и нажмите **Удалить**. При штатном выходе QuickDNS удаляет маршруты текущего сеанса. После аварийного завершения запись может остаться до перезагрузки Windows.

Маршруты применяются ко всем приложениям по IP-адресу назначения.

## Вопросы и ответы (FAQ)

<details>
<summary><b>Нужно ли устанавливать дополнительные библиотеки (.NET, Visual C++ Redistributable)?</b></summary>
Для запуска QuickDNS устанавливать .NET или Visual C++ Redistributable не требуется. Сборка со встроенным движком содержит sing-box в самом QuickDNS.exe.
</details>

<details>
<summary><b>Зачем программе требуются права Администратора?</b></summary>
Изменение системных параметров сетевых адаптеров в Windows является привилегированной операцией. Без прав Администратора операционная система блокирует вызовы API настройки сетевых интерфейсов. В исполняемый файл встроен манифест <code>requireAdministrator</code>, поэтому запрос UAC появляется автоматически при запуске.
</details>

<details>
<summary><b>Где сохраняются добавленные профили?</b></summary>
Пользовательские профили сохраняются в системной директории пользователя в формате JSON:<br/>
<code>%APPDATA%\QuickDNS\profiles.json</code><br/>
Файл создается автоматически и синхронизируется в потокобезопасном режиме.
</details>

<details>
<summary><b>Как вернуть настройки DNS по умолчанию?</b></summary>
Выберите профиль <b>«Автоматически (DHCP)»</b> и нажмите «Применить DNS в 1 клик». Программа переведет адаптер в автоматический режим получения DNS от вашего роутера или провайдера.
</details>

<details>
<summary><b>Как проверяется целостность и безопасность при автообновлении?</b></summary>
Обновления скачиваются по HTTPS с разрешённых доменов GitHub. Перед запуском нового исполняемого файла программа загружает <code>QuickDNS.exe.sha256</code> из релиза и сравнивает его с контрольной суммой файла. При несовпадении или отсутствии файла контрольной суммы обновление блокируется. SHA-256 позволяет обнаружить несовпадение файлов, но не является цифровой подписью издателя.
</details>

## Архитектура и стек технологий

* **Язык разработки:** C++20 (Win32 API, STL).
* **Сетевые интерфейсы:** Windows **IP Helper API** (`GetAdaptersAddresses`, `SetInterfaceDnsSettings` для Windows 10 1809+ / Windows 11 с автоматическим fallback на `netsh`).
* **Очистка кэша:** Windows **DNS API** (`DnsFlushResolverCache` из `dnsapi.dll`).
* **Графика и стиль:** Windows **DWM API** (`DwmSetWindowAttribute`), **GDI+** с субпиксельным сглаживанием (`SmoothingModeAntiAlias`), **Common Controls v6**.
* **Хранилище настроек:** DNS-профили и правила приложений хранятся отдельно в JSON-файлах в `%APPDATA%\QuickDNS`.
* **Система сборки:** CMake 3.20+ и скрипт `build.bat` (LLVM-MinGW / MSVC).

## Структура проекта

- `include/`, `src/` — интерфейсы и реализация DNS, маршрутизации и окон приложения.
- `tests/` — тесты конфигурации, интерфейса, сетевых компонентов и обновления.
- `res/` — ресурсы приложения, включая иконки и манифест.
- `scripts/`, `tools/` — упаковка релиза и вспомогательные инструменты.
- `third_party/` — сторонние компоненты и их лицензии.
- `.github/workflows/` — сборка, тестирование и публикация релиза в GitHub Actions.

## Сборка из исходников

### Вариант 1: Быстрая сборка через `build.bat`
```cmd
git clone https://github.com/szanko02/QuickDNS.git
cd QuickDNS
build.bat
```
Проверенная среда сборки — Visual Studio 2026 с компонентом «Разработка классических приложений на C++» и Windows SDK 10.0.26100.
Скрипт соберёт приложение и тесты через CMake и скопирует `QuickDNS.exe` в корень проекта.
Скрипт также принимает путь к `bin` LLVM-MinGW или MSYS2. Этот вариант для текущей версии не проверен.

### Вариант 2: Сборка через CMake
```cmd
git clone https://github.com/szanko02/QuickDNS.git
cd QuickDNS
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure -LE network
```

## Права доступа (UAC)

Смена DNS в операционных системах семейства Windows затрагивает общесистемные параметры сетевых адаптеров. В исполняемый файл встроен манифест `requireAdministrator`, поэтому Windows автоматически запрашивает подтверждение запуска с повышенными правами.
