## 💡 Зачем нужен QuickDNS?

В стандартном интерфейсе Windows 10 и 11 для смены DNS требуется пройти через длинную цепочку меню: открыть «Параметры» → «Сеть и Интернет» → «Дополнительные сетевые параметры» → «Свойства адаптера» → «IP версии 4» → вручную вписать IP-адреса → нажать «ОК» → открыть командную строку и выполнить `ipconfig /flushdns`.

**QuickDNS решает эту задачу за 1 секунду:**
1. Открываете программу (или кликаете по значку в трее).
2. Выбираете нужный профиль (Comss.one, GeoHide, Cloudflare и др.).
3. Нажимаете **«Применить»** — DNS изменен, а системный кэш DNS мгновенно очищен.

## ✨ Ключевые возможности

* ⚡ **Смена DNS в 1 клик:** Мгновенное применение настроек к активному сетевому адаптеру (Ethernet / Wi-Fi) без перезагрузки системы.
* 🛡️ **Готовые предустановленные профили:** Популярные DNS-серверы для защиты, приватности, ускорения и обхода региональных ограничений уже вшиты в программу.
* ➕ **Интерактивное добавление своих DNS:** Удобное диалоговое окно прямо в интерфейсе — добавляйте любые серверы с встроенной валидацией IPv4-адресов без необходимости редактировать файлы вручную.
* 🗑️ **Управление профилями:** Удаление пользовательских профилей в один клик.
* 🔔 **Интеграция с системным треем:**
  * Сворачивание окна в область уведомлений возле часов.
  * Меню быстрого переключения по правому клику: **меняйте DNS прямо из панели задач**, не открывая основное окно.
  * Нативные всплывающие уведомления Windows (Balloon Tooltips) при успешной смене сервера.
* 🧹 **Автоматический сброс кэша DNS:** После каждой смены программа автоматически вызывает системную функцию сброса кэша сопоставителя (`DnsFlushResolverCache` — аналог команды `ipconfig /flushdns`).
* 🎨 **Нативный дизайн Windows 11:**
  * Поддержка **Immersive Dark Mode** (автоматический темный стиль заголовка окна и контролов).
  * Скругленные углы окна (DWM Window Corner Preference).
  * Современная типографика Segoe UI Variable и полноценная поддержка мониторов высокого разрешения (**Per-Monitor V2 High-DPI**).
* 🪶 **Максимальная легковесность и скорость:**
  * Написан на чистом **C++20** и нативном **Win32 API**.
  * Никакого Electron, WebView2, .NET Runtime или сторонних тяжелых фреймворков.
  * Весь исполняемый файл скомпилирован статически в один компактный `.exe` (~1.8 МБ).
  * Потребление памяти в трее — всего ~8 МБ RAM, 0% CPU в режиме ожидания.

## 🚀 Инструкция по использованию

1. Скачайте [`QuickDNS.exe`](https://github.com/szanko02/QuickDNS/releases/latest) или распакуйте `QuickDNS-v1.0.0-Portable.zip`.
2. Запустите **`QuickDNS.exe`** (при первом запуске подтвердите стандартный запрос прав Администратора UAC — это необходимо Windows для настройки сетевых карт).
3. Программа автоматически выберет ваш активный адаптер (Wi-Fi или Ethernet).
4. Выберите нужный DNS-профиль из выпадающего списка.
5. Нажмите кнопку **«⚡ Применить DNS в 1 клик»** — настройки применятся мгновенно.
6. Для быстрого переключения в будущем сверните программу: кликните правой кнопкой мыши по значку в трее возле часов и выберите любой сервер.

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>Нужно ли устанавливать какие-либо библиотеки (.NET, Visual C++ Redistributable)?</b></summary>
Нет! QuickDNS скомпилирован со статической линковкой C++ Runtime (UCRT). В системе не требуется наличие сторонних библиотек или сред выполнения.
</details>

<details>
<summary><b>Зачем программе требуются права Администратора?</b></summary>
Изменение системных параметров сетевых адаптеров в Windows является привилегированной операцией. Без прав Администратора операционная система блокирует вызовы API настройки сетевых интерфейсов. В исполняемый файл встроен манифест <code>requireAdministrator</code>, поэтому запрос UAC появляется автоматически при запуске.
</details>

<details>
<summary><b>Где сохраняются добавленные профили?</b></summary>
Пользовательские профили сохраняются в стандартной системной директории пользователя в формате JSON:<br/>
<code>%APPDATA%\QuickDNS\profiles.json</code><br/>
Файл создается автоматически и синхронизируется в потокобезопасном режиме.
</details>

<details>
<summary><b>Как вернуть настройки DNS обратно по умолчанию?</b></summary>
Просто выберите профиль <b>«Автоматически (DHCP)»</b> и нажмите «Применить DNS в 1 клик». Программа переведет адаптер в автоматический режим получения DNS от вашего роутера или интернет-провайдера.
</details>

## 🛠 Архитектура и стек технологий

* **Язык разработки:** Modern **C++20** (чистый Win32 API, STL).
* **Сетевые интерфейсы:** Windows **IP Helper API** (`GetAdaptersAddresses`, `SetInterfaceDnsSettings` для Windows 10 1809+ / Windows 11 с автоматическим fallback на `netsh`).
* **Очистка кэша:** Windows **DNS API** (`DnsFlushResolverCache` из `dnsapi.dll`).
* **Графика и стиль:** Windows **DWM API** (`DwmSetWindowAttribute`), **Common Controls v6**.
* **Хранилище настроек:** JSON в `%APPDATA%\QuickDNS\profiles.json` (потокобезопасный `std::mutex`, кодировка UTF-8 / UTF-16).
* **Система сборки:** CMake 3.20+ и оптимизированный скрипт `build.bat` (LLVM-MinGW / MSVC).

## 🔨 Сборка из исходников

Если вы хотите собрать проект самостоятельно:

### Вариант 1: Быстрая сборка через `build.bat`
```cmd
git clone https://github.com/szanko02/QuickDNS.git
cd QuickDNS
build.bat
```
*Скрипт автоматически скомпилирует ресурсы, сетевое ядро, GUI и создаст готовый `QuickDNS.exe` прямо в корневой папке проекта.*

### Вариант 2: Сборка через CMake (Visual Studio 2022)
```cmd
git clone https://github.com/szanko02/QuickDNS.git
cd QuickDNS
mkdir build && cd build
cmake .. -G "Visual Studio 17 2022" -A x64
cmake --build . --config Release
```

## 🔒 Права доступа (UAC)

Смена DNS в операционных системах семейства Windows затрагивает общесистемные параметры сетевых адаптеров. В исполняемый файл встроен манифест `requireAdministrator`, поэтому Windows автоматически запрашивает подтверждение запуска с повышенными правами.
